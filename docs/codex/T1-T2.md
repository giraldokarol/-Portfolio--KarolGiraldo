## T1 — `Avatar.tsx`

Convierte `src/assets/avatar/avatar.svg` en un componente React con el **SVG en línea** (no `<img>`),
porque después GSAP animará sus capas internas.

1. Copia **exactamente** la geometría (`d`, `stroke-width`, `stroke-linecap`, `stroke-linejoin`, orden de capas
   y anidación de grupos). No simplifiques ni "optimices" los trazados.
2. Cada `id="x"` → `data-part="x"` (los ids se duplicarían si el avatar aparece dos veces). Conserva **todos**
   los grupos (`avatar`, `girl`, `hair-back`, `ears`, `ear-*`, `neck`, `face`, `eye-*`, `eyeball-*`, `lashes-*`,
   `frame`, `anchor`, `anchor-point-*`).
3. Atributos en JSX: `stroke-width` → `strokeWidth`, etc. Quita `width`/`height` del `<svg>` y conserva
   `viewBox="0 0 356 380"`. El tamaño lo da el CSS.
4. Colores **sin hex en el componente**:
   - Todas las líneas azules: `stroke="currentColor"`, y en SCSS `.avatar { color: var(--avatar-line); }`.
   - Rellenos con clases definidas en `_avatar.scss`:

     | Capa | Clase | Token |
     |---|---|---|
     | `pupil-*` (relleno azul) | `avatar__ink` | `fill: currentColor` |
     | `*-skin` | `avatar__skin` | `--avatar-skin` |
     | `cheek-*` | `avatar__cheek` | `--avatar-cheek` |
     | `nose` | `avatar__nose` | `--avatar-nose` |
     | `neck-shadow` | `avatar__neck-shadow` | `--avatar-neck-shadow` |
     | `anchor-dot-*` | `avatar__accent` | `--avatar-accent` |
5. Props: `className?: string` y `label?: string`.
   - Con `label`: `role="img"` + `aria-label={label}`.
   - Sin `label`: `aria-hidden="true"`.
   - Añade `focusable="false"`.
6. Nuevos tokens en `src/styles/base/_root.scss` (dentro de `:root`, sin cambiar los existentes):
   ```scss
   // Avatar
   --avatar-line: var(--color-primary);
   --avatar-skin: #ffffff;
   --avatar-cheek: #f0f5fc;
   --avatar-nose: #94b0dd;
   --avatar-neck-shadow: #d7e4f2;
   --avatar-accent: var(--color-accent);
   ```
7. `_avatar.scss`: `.avatar { display: block; width: 100%; height: auto; overflow: visible; color: var(--avatar-line); }`
   + las clases de color. Sin animaciones.
8. Texto alternativo nuevo `hero.avatarAlt`:
   - en: `"Illustrated avatar of Karol Giraldo"`
   - fr: `"Avatar illustré de Karol Giraldo"`
   - es: `"Avatar ilustrado de Karol Giraldo"`
